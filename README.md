# Öğrenci Not ve Başarı Sistemi

Python kullanılarak geliştirilmiş basit bir öğrenci not ve başarı değerlendirme sistemi.

## Projenin Özellikleri

- Öğrenci adı ve soyadı girişi
- Vize ve final notu girişi
- Notların 0-100 arasında olup olmadığının kontrolü
- Devamsızlık kontrolü
- Ortalama hesaplama
- Harf notu hesaplama
- Hatalı girişlerin kontrol edilmesi
- Başarı durumunun gösterilmesi

## Kullanılan Python Konuları

- Değişkenler
- `input()`
- `float()`
- `if / elif / else`
- `while` döngüsü
- Mantıksal operatörler (`and`, `or`)
- Karşılaştırma operatörleri
- String metotları (`lower()`)

## Nasıl Çalıştırılır?

Terminal üzerinden:

```bash
python ogrenci_not_sistemi.py
